
## Общая цель

Переделать парсер метаданных

## Описание

Мне нужно полностью передалать парсер метаданных.
Результатом парсинга должна быть структура каталогов с файлами yaml.
Каталог нужно задавать в настройках, у меня будет tmp/parser_data/
Внутри будет корневой каталог cf, в нем подкаталоги для различных типов метаданных и файл configuration.yaml с перечнем всех объектов.
Нас интересуют типы метаданных:
Catalogs
Constants
Documents
Enums
(будут еще добавляться)
В yaml файле метаданного должна быть исчерпывающая информация о таблице (нужная для создания ее в СУБД), адрес исходного файла, все реквизиты и их свойства, все табличные части. 

Нужна команда для вызова парсинга.
Конструктор запросов будет работать с yaml файлами напрямую или сделает себе кэш из них.
