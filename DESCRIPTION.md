
## Общая цель

Сделать vsix расширение для vs code - конструктор запросов 1С.

## Реализация

ОБЯЗАТЕЛЬНО используем ТDD и Playwright (если применимо)

## Возможности

- Визуальное построение: Позволяет добавлять таблицы (справочники, документы, регистры), выбирать поля и связывать таблицы между собой с помощью мыши, задавая условия соединения (левое, правое, полное, внутреннее).
- Связи и псевдонимы: Дает возможность создавать логические связи между таблицами, указывать условия для полей и присваивать таблицам краткие псевдонимы (синонимы) для удобства.
- Группировка и итоги: Позволяет указать группировку данных (например, по контрагентам или номенклатуре) и расчет итогвых показателей (сумма, количество, максимум/минимум).
- Условия и фильтрация: Позволяет задавать условия отбора записей (фильтры).
- Сортировка: Позволяет указать сортировку (по возрастанию или убыванию) по нескольким полям сразу.
- Работа с пакетами: Поддерживает создание пакетных запросов (когда результат одного запроса используется в следующем), а также создание временных таблиц.

## Контекст

Для работы с конфигурацией 1С она выгружается в файлы (пример в src/cf). Код находится в файлах *.bsl , метаданные, формы и прочее в *.xml

Чтобы воссоздать полноценный конструктор, аналогичный тому, что есть в «Конфигураторе» или EDT, нужно не просто нарисовать интерфейс, но и решить две фундаментальные проблемы:
- Парсинг запросов — научиться разбирать текст запроса на составные части (поля, таблицы, условия).
- Получение метаданных — понять, какие поля существуют у таблиц, какие типы данных у этих полей, какие связи между таблицами.

Что уже есть:
- Грамматика для парсинга (tree-sitter-bsl) : Существует готовый парсер для языка запросов 1С (SDBL), написанный на Rust, который можно использовать в Node.js окружении VS Code . Это решит проблему №1 — он умеет разбирать запрос на абстрактное синтаксическое дерево (AST) и даже понимает синтаксис временных таблиц и объединений. Смотри проект в /tmp/tree-sitter-bsl
- Дерево метаданных 1С для VS Code : В расширении 1C: Platform Tools есть дерево метаданных и отладка, но нет конструктора запросов . Смотри проект в /tmp/vscode-1c-platform-tools

Скриншоты работы конструктора запросов в 1С: tmp/console_screenshots/

Возможно, портебуется сначала распарсить все метаданные, сохранить это в удобочитаемом виде, а только потом работать с конструктором.

В помощь для разработки:

- mcp 1c-copilot-proxy - вопросы 1с-AI помощнику, ответит на любой вопрос по 1С
