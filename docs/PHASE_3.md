# Фаза 3. Доработка UI конструктора

← [Дорожная карта](ROADMAP.md)

✅ Готово.

Спек: [`specs/2026-06-03-phase3-ui-design.md`](superpowers/specs/2026-06-03-phase3-ui-design.md)
План: [`plans/2026-06-02-phase3-ui-fixes.md`](superpowers/plans/2026-06-02-phase3-ui-fixes.md)

- Drag&drop таблиц, реквизитов и табличных частей между тремя панелями.
- Табличные части в дереве метаданных и в блоке Таблицы; вложенные поля ТЧ в блоке
  Поля с возможностью выборочного удаления подполей.
- Раскрытие ссылочных реквизитов в дереве и в блоке Таблицы.
- Синтаксис `Таблица.ТЧ.(поле1, поле2, ...) КАК ТЧ` в генераторе запросов.
- Кнопка «ОК» вставляет BSL-строку (`"ВЫБРАТЬ\n|..."`) в позицию курсора `.bsl`-файла
  и закрывает конструктор; кнопка «Отмена» закрывает без вставки.
- Кнопка «Запрос» — просмотр текущего текста запроса в модальном окне.
- Контекстное меню для `.bsl`-файлов; позиция курсора фиксируется до открытия webview.
- Исправлена буква «ё» в именах стандартных реквизитов.
- Путь к YAML резолвится от `extensionUri` при отсутствии workspace.
