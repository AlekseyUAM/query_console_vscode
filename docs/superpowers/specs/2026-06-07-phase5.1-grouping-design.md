# Фаза 5.1 — Вкладка «Группировка» (дизайн)

ТЗ: `tmp/группировка.md`. Скриншоты: `tmp/console_screenshots/Screenshot_20260607_213915.png`
(несколько группировок), `…_214050.png` (одна группировка).

## Цель

Добавить вкладку «Группировка»: пользователь распределяет выбранные поля на **поля
группировки** и **суммируемые поля** (с агрегатной функцией). Генератор SDBL
оборачивает суммируемые поля функцией в `ВЫБРАТЬ` и добавляет секцию
`СГРУППИРОВАТЬ ПО` (или `СГРУППИРОВАТЬ ПО ГРУППИРУЮЩИМ НАБОРАМ`).

## Модель (`src/core/query/queryModel.ts`)

```ts
export type AggregateFunction =
  | 'Сумма' | 'Количество' | 'КоличествоРазличных'
  | 'Максимум' | 'Минимум' | 'Среднее';

/** Ссылка на выбранное поле выборки (совпадает с парой из SelectedField). */
export interface FieldRef { tableId: string; path: string; }

export interface SummableField extends FieldRef { func: AggregateFunction; }

export interface Grouping {
  /** «Использовать несколько группировок» */
  multiple: boolean;
  /** Поля группировки (один набор), в порядке добавления. */
  groupFields: FieldRef[];
  /** Наборы группировки (multiple=true), каждый — список полей. */
  groupSets: FieldRef[][];
  /** Суммируемые поля с функцией. */
  aggregates: SummableField[];
}

export interface QueryModel {
  // …существующее…
  grouping?: Grouping;
}
```

Группировка **активна**, когда `grouping` задан и `(groupFields|groupSets непусты)` или
есть `aggregates`. Поле `grouping` опционально — при отсутствии генерация не меняется.

## Маппинг функции → SDBL

| Функция (UI)          | Текст                                  |
|-----------------------|----------------------------------------|
| Сумма                 | `СУММА(<выр>)`                          |
| Количество            | `КОЛИЧЕСТВО(<выр>)`                     |
| КоличествоРазличных   | `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ <выр>)`           |
| Максимум              | `МАКСИМУМ(<выр>)`                       |
| Минимум               | `МИНИМУМ(<выр>)`                        |
| Среднее               | `СРЕДНЕЕ(<выр>)`                        |

`<выр>` = `Псевдоним.Поле` (как обычное поле выборки).

## Генератор SDBL (`src/core/query/sdblGenerator.ts`)

1. **ВЫБРАТЬ.** Для каждого `SelectedField` без `expression`: если пара
   `(tableId, path)` есть в `grouping.aggregates` — рендерить
   `<func-wrap>(Псевдоним.Поле) КАК <alias>` (alias по тем же правилам, что и сейчас —
   `f.alias`, иначе без `КАК`). Иначе — как сейчас. Порядок полей в `ВЫБРАТЬ` не
   меняется.
2. **СГРУППИРОВАТЬ ПО** — после `ИЗ` (и после `ГДЕ`, когда появится 5.2; в 5.1 — сразу
   после `ИЗ`). Рендерится, только если группировка активна и есть поля группировки.
   - `multiple=false`: 
     ```
     СГРУППИРОВАТЬ ПО
     	<Псевдоним.Поле>,
     	<Псевдоним.Поле>
     ```
   - `multiple=true`:
     ```
     СГРУППИРОВАТЬ ПО ГРУППИРУЮЩИМ НАБОРАМ
     (
     	(<поле>,
     	<поле>),
     	(<поле>)
     )
     ```
     Наборы разделяются `,`; внутри набора поля — `,`; пустые наборы пропускаются.

Формат секции — **детерминированный канонический** (валидный SDBL, проверяется
`validate_query`). Точное воспроизведение причудливых отступов 1С-конструктора
(пробелы выравнивания внутри наборов из ТЗ) не требуется — приоритет: валидность +
структура (наборы в скобках, функции-обёртки). Голден-сьют 4.5 не затрагивается
(в нём нет группировки).

## Webview

- `TabsBar` — сделать вкладки переключаемыми (активная вкладка в состоянии App).
  Вкладка «Таблицы и поля» — существующий контент; «Группировка» — новый
  `GroupingTab`. Прочие вкладки 1С (Условия, Дополнительно, …) показываются как
  заголовки и наполняются в 5.2–5.4.
- `GroupingTab` (новый компонент): три списка — «Поля» (выбранные поля выборки, не
  ТЧ), «Поле группировки», «Суммируемое поле | Функция». Перетаскивание поля из
  «Поля» в группировку или в суммируемые. Для суммируемого — выпадающий выбор функции
  (числовое поле → все 6; нечисловое → без Сумма/Среднее; тип берём из
  `MetaField.type`/категории — если тип неизвестен, показываем нечисловой набор).
  Галочка «Использовать несколько группировок» переключает список группировки на дерево
  наборов с кнопками добавить/удалить набор.
- Состояние группировки живёт в `queryStore` (`grouping` в state); экшены:
  `SET_GROUPING_MULTIPLE`, `ADD_GROUP_FIELD`, `REMOVE_GROUP_FIELD`,
  `ADD_SUMMABLE_FIELD`, `REMOVE_SUMMABLE_FIELD`, `SET_SUMMABLE_FUNC`, плюс операции с
  наборами (`ADD_GROUP_SET`, `REMOVE_GROUP_SET`, `ADD_FIELD_TO_SET`, …).
- `App.handleShowQuery`/`FieldsPanel.handleOk` передают `grouping` в `generate`.

## Не входит

ИМЕЮЩИЕ (HAVING), агрегаты в произвольных выражениях, перетаскивание между наборами,
синхронизация с другими вкладками сверх общего `QueryModel`.
