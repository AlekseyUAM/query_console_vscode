# Фаза 5.6 — Вкладка «Порядок» (дизайн)

ТЗ: `tmp/порядок.md`. Скриншот: `tmp/console_screenshots/Screenshot_20260608_094038.png`.

## Цель

Добавить вкладку «Порядок»: пользователь переносит выбранные поля в список сортировки и
задаёт направление (Возрастание/Убывание). Генератор дорисовывает секцию
`УПОРЯДОЧИТЬ ПО` и, при установленной галочке, `АВТОУПОРЯДОЧИВАНИЕ`.

## Модель (`src/core/query/queryModel.ts`)

```ts
export type SortDirection = 'asc' | 'desc';

export interface OrderField {
  tableId: string;
  path: string;
  /** asc → без суффикса; desc → УБЫВ. */
  direction: SortDirection;
}

export interface Order {
  fields: OrderField[];
  /** «Автоупорядочивание» → ключевое слово АВТОУПОРЯДОЧИВАНИЕ. */
  auto: boolean;
}

export interface QueryModel {
  // …существующее…
  order?: Order;
}
```

Порядок **активен**, когда `order.fields` непуст или `order.auto`. При отсутствии
`order`/неактивном — генерация байт-в-байт как сейчас.

## Ссылка на поле

Сортировка ссылается на поле по **псевдониму выборки** (как в эталоне:
`ВЫБРАТЬ Валюты.Ссылка КАК Ссылка … УПОРЯДОЧИТЬ ПО Ссылка`). Псевдоним = `alias`
соответствующего `SelectedField`, иначе последний сегмент `path`. Хелпер находит поле в
`model.fields` по паре `(tableId, path)`; если не найдено — последний сегмент `path`.

## Генератор SDBL (`src/core/query/sdblGenerator.ts`)

Новый хелпер `renderOrder(order, model): string[]` (без ведущей пустой строки):

```
УПОРЯДОЧИТЬ ПО
	<полеA>,
	<полеB> УБЫВ
```

- Каждое поле: `<псевдоним>` + (` УБЫВ` при `direction==='desc'`); запятая после всех,
  кроме последнего.
- Если `auto` — добавить строку `АВТОУПОРЯДОЧИВАНИЕ` (даже без полей: при `fields=[]` и
  `auto` секция = только `АВТОУПОРЯДОЧИВАНИЕ`).

**Встраивание.** `УПОРЯДОЧИТЬ ПО` идёт после блока запроса (после `ДЛЯ ИЗМЕНЕНИЯ`),
отделяясь **пустой строкой** (эталон ТЗ):

```
ИЗ
	Справочник.Валюты КАК Валюты

УПОРЯДОЧИТЬ ПО
	Ссылка
```

`generate()`: `out = buildQueryBlock(...)`; если `renderOrder` непуст —
`out += '\n\n' + orderLines.join('\n')`. (Секция `ИТОГИ` 5.7 дописывается после
`УПОРЯДОЧИТЬ ПО` без пустой строки — см. спек 5.7.)

В объединении (`generateDocument`, >1 участник) `УПОРЯДОЧИТЬ ПО`/`ИТОГИ` **не
рендерятся** (относятся к запросу в целом — вне рамок этой итерации); одиночный запрос
идёт через `generate()` и секцию получает.

## Webview

- `TabsBar`: добавить «Порядок» в конец списка вкладок (после
  «Объединения/Псевдонимы»).
- `OrderTab` (новый): два списка — «Поля» (выбранные поля выборки, draggable) и
  «Сортировка» (колонки `Поле`, `Сортировка`). Перетаскивание поля из «Поля» в
  «Сортировка» добавляет `OrderField` (`direction='asc'`). Колонка «Сортировка» —
  выпадающий список (`Возрастание`/`Убывание`). Кнопка «✕» удаляет. Галочка
  «Автоупорядочивание» под списком.
- Состояние `order` в `queryStore`; экшены: `ADD_ORDER_FIELD`, `REMOVE_ORDER_FIELD`,
  `SET_ORDER_DIRECTION`, `SET_ORDER_AUTO`. Каскад: `REMOVE_TABLE`/`REMOVE_FIELD` удаляют
  поля сортировки на удалённые таблицу/поле.
- `order` добавляется в `SavedQuery`, `snapshotActive`, `restoreSaved`,
  `buildModelFromFlat`, `initialState`
  (`order: { fields: [], auto: false }`).

## Не входит

Перетаскивание-переупорядочивание строк сортировки (стрелки вверх/вниз — порядок =
порядок добавления), сортировка по произвольному выражению, `УПОРЯДОЧИТЬ ПО` для
объединения.
