## Принципы

1. **Оракул — единственный источник правил.** Каждое правило выводится сравнением
   `ours ¦ oracle` на реальных файлах, проверяется побайтно. Никакого хардкода строк
   корпуса.
2. **Принято только растёт; ноль регрессий.** Гейт каждого шага: `npm run accept:oracle`
   — `accepted` строго больше прежнего, целевой класс падает, прочие не растут; плюс
   `npm run test:unit` зелёный (867+).
3. **Парсер по умолчанию чист** (text→model, без метаданных). Резолвер метаданных
   (класс B) — **необязательная** инъекция в `parseBatch`, не меняющая поведение по
   умолчанию.
4. **Гейтирование изменений.** Новое поведение включается только при наличии триггера
   (узла/токена), запросы без него — байт-в-байт прежние.

## Критерий приёмки фазы

`report.json` пуст (mismatch = 0, parse-exception = 0) ⇒ **1976/1976**. Если класс не
сводится к чистому правилу в рамках итерации — он явно документируется в ROADMAP как
остаток с обоснованием, приёмка при этом только растёт и без регрессий.
