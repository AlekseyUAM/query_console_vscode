# Фаза 6.15 — разбор и снижение остатка mismatch (202) — дизайн

## Контекст

Приёмка `npm run accept:oracle`: 1976 запросов корпуса `tmp/query1c`,
критерий `generateBatch(parseBatch(input)) === query_text` (канон конструктора 1С,
`tmp/query1c/oracle/golden.jsonl`). Текущее: принято 1774, отклонено 202,
parse-exception 0 — все отказы это расхождения рендера/модели с каноном.

## Цель

1. Классифицировать все 202 mismatch по первопричинам (классификация по первому
   диффу сохранена в `tmp/mismatch-classes.json`).
2. Исправить все категории, которые исправимы локально (правила рендера/парсера),
   подтверждая каждое новое правило живым оракулом MCP `1c-md validate_query`
   (урок 6.13/6.14: гипотезы — только через живой оракул).
3. Категории, требующие метаданных конфигурации или реконструкции дерева
   конструктором (например, разворачивание `ВЫБРАТЬ *` в полный список полей,
   разворачивание `.()` табличных частей), задокументировать как неустранимый
   остаток с точным количеством.
