# Фаза 5.7 — Вкладка «Итоги» (дизайн)

ТЗ: `tmp/итоги.md`. Скриншоты: `tmp/console_screenshots/Screenshot_20260608_101011.png`
(группировочное поле + тип итогов + псевдоним), `…_101535.png` (итоговое поле/выражение).

## Цель

Добавить вкладку «Итоги»: пользователь задаёт **группировочные поля** (с типом итогов и
псевдонимом) и **итоговые поля** (числовые, с выражением-агрегатом). Генератор дорисовывает
секцию `ИТОГИ … ПО …`.

## Модель (`src/core/query/queryModel.ts`)

```ts
/** Тип итогов группировочного поля. */
export type TotalKind = 'elements' | 'hierarchy' | 'onlyHierarchy';

export interface TotalGroupField {
  tableId: string;
  path: string;
  /** elements → нет; hierarchy → ИЕРАРХИЯ; onlyHierarchy → ТОЛЬКО ИЕРАРХИЯ. */
  kind: TotalKind;
  /** Псевдоним группировки (КАК …), опционально. */
  alias?: string;
}

export interface TotalField {
  tableId: string;
  path: string;
  /** Выражение агрегата; по умолчанию СУММА(<псевдоним>). */
  expression?: string;
}

export interface Totals {
  groupFields: TotalGroupField[];
  totalFields: TotalField[];
  /** «Общие итоги» → ОБЩИЕ первым элементом списка ПО. */
  grand: boolean;
}

export interface QueryModel {
  // …существующее…
  totals?: Totals;
}
```

Итоги **активны**, когда `groupFields` непуст или `grand`. При отсутствии/неактивности —
генерация байт-в-байт как сейчас.

## Ссылка на поле

Группировочное и итоговое поле ссылаются по **псевдониму выборки** (как сортировка в
5.6): `alias` соответствующего `SelectedField`, иначе последний сегмент `path`.

## Маппинг типа итогов → SDBL

| kind          | суффикс группировочного поля |
|---------------|------------------------------|
| elements      | (нет)                        |
| hierarchy     | ` ИЕРАРХИЯ`                   |
| onlyHierarchy | ` ТОЛЬКО ИЕРАРХИЯ`           |

Группировочное поле: `<псевдоним><суффикс>` + (` КАК <alias>` если задан `alias`).

## Генератор SDBL (`src/core/query/sdblGenerator.ts`)

Новый хелпер `renderTotals(totals, model): string[]` (без ведущей пустой строки):

- Список агрегатов = `totalFields`, каждый: `expression ?? СУММА(<псевдоним>)`.
- Список ПО: если `grand` — первым `ОБЩИЕ`; затем каждое группировочное поле.
- Формат:
  - **Есть итоговые поля:**
    ```
    ИТОГИ
    	СУММА(Наценка)
    ПО
    	Ссылка
    ```
  - **Нет итоговых полей:**
    ```
    ИТОГИ ПО
    	Ссылка КАК Ссылка11
    ```
  - **«Общие итоги»** (эталон ТЗ):
    ```
    ИТОГИ ПО
    	ОБЩИЕ,
    	Ссылка ТОЛЬКО ИЕРАРХИЯ КАК Ссылка11
    ```
  Элементы списков (агрегаты, ПО) — через запятую, последний без запятой, отступ 1 таб.

**Встраивание.** `ИТОГИ` идёт после `УПОРЯДОЧИТЬ ПО` (5.6) **без** ведущей пустой строки
(эталон ТЗ: `ИЗ … \nИТОГИ ПО`). `generate()`: после `buildQueryBlock` и возможной секции
`УПОРЯДОЧИТЬ ПО` — если `renderTotals` непуст, `out += '\n' + totalsLines.join('\n')`.
В объединении (>1 участник) не рендерится (см. спек 5.6).

## Webview

- `TabsBar`: добавить «Итоги» в конец (после «Порядок»).
- `TotalsTab` (новый): слева список «Поля» (draggable); справа сверху — «Группировочное
  поле» (колонки `Группировочное поле`, `Тип итогов`, `Псевдоним`), под ним галочка
  «Общие итоги», ниже — «Итоговое поле» (колонки `Итоговое поле`, `Выражение`).
  - Перетаскивание поля в группировочные → `TotalGroupField` (`kind='elements'`).
    Колонка «Тип итогов» — выпадающий список: для ссылочных полей (тип содержит `ref`)
    три значения (Элементы / Элементы и иерархия / Только иерархия); для прочих — только
    Элементы. Колонка «Псевдоним» — текстовое поле (`alias`).
  - Перетаскивание поля в итоговые разрешено **только для числовых** (тип содержит
    `primitive === 'Число'`) — переиспользовать `isNumericField`-логику из `GroupingTab`.
    `TotalField` с `expression = СУММА(<псевдоним>)` по умолчанию; колонка «Выражение» —
    редактируемое текстовое поле.
- Состояние `totals` в `queryStore`; экшены: `ADD_TOTAL_GROUP_FIELD`,
  `REMOVE_TOTAL_GROUP_FIELD`, `SET_TOTAL_GROUP_KIND`, `SET_TOTAL_GROUP_ALIAS`,
  `ADD_TOTAL_FIELD`, `REMOVE_TOTAL_FIELD`, `SET_TOTAL_FIELD_EXPRESSION`, `SET_TOTAL_GRAND`.
  Каскад: `REMOVE_TABLE`/`REMOVE_FIELD` удаляют группировочные/итоговые поля на удалённые
  таблицу/поле.
- `totals` добавляется в `SavedQuery`, `snapshotActive`, `restoreSaved`,
  `buildModelFromFlat`, `initialState`
  (`totals: { groupFields: [], totalFields: [], grand: false }`).

## Не входит

Иерархия по реальному признаку «иерархический» из метаданных (тип итогов предлагается по
ссылочности поля — best-effort), вложенные итоги/периодичность в `ИТОГИ`, произвольное
группировочное поле, `ИТОГИ` для объединения.
