# Спецификация: Фаза 3 — Доработка UI конструктора

## 1. Цель

Довести вкладку «Таблицы и поля» до рабочего состояния: drag&drop, табличные части,
контекстное меню BSL-файлов, вставка текста запроса в редактор.

## 2. Реализованные возможности

### 2.1 Дерево метаданных (блок База данных)

- Объекты группируются по типам: Справочники, Документы.
- Объект раскрывается кликом → показывает реквизиты и табличные части.
- Реквизиты ссылочного типа раскрываются на 1 уровень (запрос к host через `expandRef`
  при первом раскрытии, кэш в `expandedRefs`).
- Табличные части отображаются как `[ТЧ] Имя` после реквизитов объекта.
- ТЧ раскрывается → показывает собственные поля (включая `Ссылка`, `НомерСтроки`).
- Таблицы (объекты) перетаскиваются в блок **Таблицы** (`kind: 'table'`).
- Реквизиты перетаскиваются в блок **Поля** (`kind: 'field'`); таблица добавляется
  автоматически.
- ТЧ перетаскиваются в блок **Поля** (`kind: 'tabularsection'`) → вложенный реквизит
  ТЧ; либо в блок **Таблицы** → как отдельная таблица запроса.

### 2.2 Блок Таблицы

- Принимает drop таблиц и ТЧ из дерева.
- Выбранная таблица раскрывается кликом → показывает реквизиты и ТЧ.
- Реквизиты ссылочного типа раскрываются (те же `expandedRefs`, что и в дереве).
- ТЧ раскрываются → их поля тоже перетаскиваются в блок Поля.
- Реквизиты и поля ТЧ перетаскиваются в блок **Поля**.
- Кнопка ✕ убирает выбранную таблицу (вместе с её полями и ТЧ-реквизитами).

### 2.3 Блок Поля

- Принимает drop реквизитов (`kind: 'field'`) и ТЧ (`kind: 'tabularsection'`).
- Обычные поля отображаются как `Алиас.Путь`, удаляются кнопкой ✕.
- Табличные части отображаются как раскрываемый узел `Алиас.ТЧ` с вложенными полями;
  каждое подполе удаляется независимо.
- Удаление последнего подполя ТЧ удаляет весь узел ТЧ.
- Кнопка **ОК**: генерирует текст запроса локально, форматирует как BSL-строку
  (`"ВЫБРАТЬ\n|..."`), вставляет в позицию курсора активного `.bsl`-редактора,
  закрывает конструктор.
- Кнопка **Отмена**: закрывает конструктор без вставки.

### 2.4 Кнопка Запрос (нижняя панель)

- Открывает модальное окно с текущим сгенерированным текстом запроса (читаемый вид,
  без BSL-кавычек).
- Закрывается кнопкой ✕ или кликом по фону.
- Обновляется при каждом открытии — всегда актуальный текст.

### 2.5 Контекстное меню VSCode

- Пункт «1С: Конструктор запроса» появляется в контекстном меню правой кнопки мыши
  для `.bsl`-файлов.
- Позиция курсора фиксируется в момент вызова команды (до открытия webview).
- Вставка происходит в сохранённую позицию через `visibleTextEditors`, фокус
  возвращается на bsl-файл.

### 2.6 Генерация текста запроса

Синтаксис `ВЫБРАТЬ ... ИЗ ...` с поддержкой:
- Обычные реквизиты: `Алиас.Реквизит`
- Вложенные ТЧ: `Алиас.ТЧ.(\n\t\tПоле КАК Поле,\n\t\t...\n\t) КАК ТЧ`
- Псевдонимы таблиц из 2-й части `fullName`; конфликты псевдонимов разрешаются
  числовым суффиксом.
- Вывод форматируется в BSL multiline string: первая строка в `"`, каждая
  последующая с префиксом `|`.

## 3. Типы данных

```ts
// Табличная часть как реквизит-поле запроса
interface SelectedTabSectionField {
  tableId: string;   // id родительской таблицы в selectedTables
  tsName: string;    // имя ТЧ, напр. "Представления"
  tsFullName: string; // полное имя, напр. "Справочник.Валюты.Представления"
  fields: string[];  // выбранные имена полей ТЧ
}

// Расширенная модель запроса
interface QueryModel {
  tables: SelectedTable[];
  fields: SelectedField[];
  tabSectionFields?: SelectedTabSectionField[];
}
```

## 4. Контракт сообщений (дополнения к MVP)

| Направление | Тип | Действие |
|---|---|---|
| webview → host | `insertText` | вставить текст в редактор, закрыть панель |
| webview → host | `cancel` | закрыть панель без действий |
| webview → host | `expandRef` | запросить поля ссылочного типа |
| host → webview | `refFields` | ответ с полями ссылочного типа |

## 5. Исправления парсера метаданных

- Убрана буква «ё» из стандартных имён реквизитов:
  `Проведён → Проведен`, `Предопределённый → Предопределенный`,
  `ИмяПредопределённыхДанных → ИмяПредопределенныхДанных`.
- Табличные части парсятся и включаются в YAML (`tabularSections`).
- При загрузке YAML: ТЧ получают синтетическое поле `Ссылка` (ref на владельца);
  добавляются в плоский `tables[]` для поиска по `fullName`.
- Путь к YAML резолвится от `context.extensionUri.fsPath` при отсутствии
  открытого workspace.
