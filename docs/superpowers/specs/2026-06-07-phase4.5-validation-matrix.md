рабочей базе 1С, без выполнения). Golden-сьют `test/unit/sdblGolden.test.ts` уже доказал,

## Покрытие периодичностей

Зависимость полей от периодичности (Период/Запись/Регистратор/Секунда…Полугодие/Год/Авто)
покрыта golden-сьютом для всех 14 значений по каждой периодической ВТ:
РегистрНакопления `Обороты`/`ОстаткиИОбороты`, РегистрБухгалтерии `Обороты`/`ОстаткиИОбороты`/
`ОборотыДтКт` — суммарно 133 golden-кейса (`npx vitest run test/unit/sdblGolden.test.ts`).

## Как воспроизвести

1. `npx vitest run test/unit/sdblGolden.test.ts` — посимвольное совпадение с эталонами.
2. Для любого текста запроса — MCP `1c-md validate_query` с этим текстом.
