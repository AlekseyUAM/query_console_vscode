## Задача 2 — Генератор: `renderSource` для подзапроса (TDD)

1. Одиночный источник-подзапрос (один внутренний `ВЫБРАТЬ`) →
   `ИЗ\n\t(ВЫБРАТЬ\n\t\t… КАК Данные`.
2. Подзапрос с `ОБЪЕДИНИТЬ ВСЕ` + внешние `СГРУППИРОВАТЬ ПО`/`ИМЕЮЩИЕ` — эталон
   спек §4, байт-в-байт.

`src/core/query/sdblGenerator.ts` — `renderSource`:
- В начале: `if (t.subquery) { const inner = generateDocument(t.subquery).split('\n');
  return inner.map((l, k) => (k === 0 ? '(' + l : '\t' + l)).join('\n') + ')'; }`
- `generateDocument` объявлена ниже в файле — доступна по hoisting (function declaration).

Проверка: новые тесты зелёные, прежние generator-тесты не тронуты.

## Задача 3 — Парсер: подзапрос в `parseTableSource` (TDD)

`test/unit/sdblParser.test.ts` — СНАЧАЛА тесты (red):
1. round-trip `generate(parseQuery(text)) === text` для текста из эталона спек §4.
2. round-trip для подзапроса без `ОБЪЕДИНИТЬ` (одиночный внутренний `ВЫБРАТЬ`).
3. Идемпотентность: `generate(parse(generate(parse(text)))) === generate(parse(text))`.

`src/core/query/sdblParser.ts` — `parseTableSource`, ветка `cur.isPunct('(')`:
- Заменить `throw` на:
  - `const open = cur.expectPunct('(');`
  - цикл по `cur.next()` со счётчиком глубины до парного `)` (`close`); `eof` →
    `throw cur.error('незакрытый подзапрос в источнике ИЗ', …)`.
  - `const innerText = cur.source.slice(open.pos + 1, close.pos);`
  - `const subquery = parseDocument(innerText);`
  - `КАК <alias>` обязателен: если нет `КАК` или алиас не ident/keyword → ошибка.
  - `return { id: 't'+index, fullName: '', alias, subquery };`
- `parseDocument` уже объявлена в этом файле (function declaration) — доступна.

Проверка: новые round-trip тесты зелёные; весь сьют зелёный.
