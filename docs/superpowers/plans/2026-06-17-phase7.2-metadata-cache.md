## Шаг 1. Модуль `src/core/metadata/modelCache.ts` (TDD)

Тест `test/unit/modelCache.test.ts` (temp-каталог через `fs.mkdtempSync(os.tmpdir())`,
структура `cf/configuration.yaml` + `cf/Catalogs/Валюты.yaml`):

1. **build-on-miss**: первый `loadMetadataCached(cfDir)` → модель с таблицей
   `Справочник.Валюты`; файл `model-cache.json` создан в `dirname(cfDir)`.
2. **cache-hit**: перезаписать `model-cache.json` подменённой моделью (другое имя
   таблицы) и `fs.utimesSync(..., future, future)` → второй вызов вернёт ПОДМЕНУ
   (доказывает чтение кэша, а не YAML).
3. **invalidate-by-mtime**: `fs.utimesSync(yamlFile, future, future)` (YAML новее кэша)
   → вызов вернёт пересобранную (настоящую) модель, не подмену.
4. **invalidate-by-version**: записать кэш с `cacheVersion: MODEL_CACHE_VERSION + 1`
   → пересобор из YAML.

Реализация:
- `MODEL_CACHE_VERSION = 1`.
- `modelCachePath(cfYamlDir) = path.join(path.dirname(cfYamlDir), 'model-cache.json')`.
- `loadMetadataCached(cfYamlDir)`:
  - `isFresh`: cache есть, `JSON.parse` ок, `cacheVersion === MODEL_CACHE_VERSION`,
    `statSync(cache).mtimeMs >= newestMtime(cfYamlDir)`.
  - fresh → вернуть `data.model`.
  - иначе → `model = loadMetadataFromYaml(cfYamlDir)`; best-effort записать
    `{ cacheVersion, model }` (try/catch, `mkdirSync recursive`); вернуть `model`.
- `newestMtime` — рекурсивный скан (копия логики из `cacheLoader.ts`, держим модуль
  самодостаточным; не тащим vscode/lib).

`npm run test:unit` → RED → GREEN.
