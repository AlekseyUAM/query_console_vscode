# План — Фаза 5.5 «Связи»

Спек: `docs/superpowers/specs/2026-06-08-phase5.5-joins-design.md`. TDD обязателен.
Базовый коммит — зелёный (437 unit-тестов). Каждая задача завершается зелёными
`npm run test:unit` и `npm run build`.

## Задача 1 — Ядро: модель + генератор `renderFrom` (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. В `queryModel.ts`: типы `JoinKind`, `Join` и поле `joins?: Join[]` в `QueryModel`
   (см. спек).
2. В `sdblGenerator.ts`:
   - Хелпер `joinKeyword(leftAll, rightAll)` и нормализация (перестановка при
     `!leftAll && rightAll`).
   - Хелпер `renderJoinCondition(join, aliases)`: простое
     `<alias>.<path> <op> <alias>.<path>`; произвольное `(<expression>)`.
   - Хелпер `renderFrom(model, aliases): string[]`: нет связей → текущие `tableLines`;
     есть связи → левоассоциативная цепочка + хвостовые несвязанные таблицы (см. спек).
   - В `buildQueryBlock` заменить инлайновый `tableLines` на `renderFrom(model, aliases)`.
3. Тесты (TDD — сначала тест): нет связей (вывод не изменился); внутреннее; левое;
   полное; правое→левое (перестановка таблиц, условие без изменений); произвольное
   условие в скобках — эталоны ТЗ посимвольно; `await assertValidSdbl(text)` на каждом.

## Задача 2 — Webview: store + TabsBar(видимость) + ConnectionsTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/ConnectionsTab.tsx` (новый).

1. `queryStore`: поле `joins: Join[]` в `QueryState` и `SavedQuery` (инициализация `[]`);
   протянуть через `snapshotActive`, `restoreSaved`, `buildModelFromFlat`, `initialState`.
   Экшены `ADD_JOIN`, `REMOVE_JOIN`, `SET_JOIN_TABLE`, `SET_JOIN_ALL`, `SET_JOIN_CUSTOM`,
   `SET_JOIN_FIELD`, `SET_JOIN_OPERATOR`, `SET_JOIN_EXPRESSION`. Каскад: в `REMOVE_TABLE`
   отфильтровать связи, ссылающиеся на удалённую таблицу. Тесты на ключевые экшены и
   каскад.
2. `TabsBar`: принять проп `tabs: string[]` (видимые вкладки) вместо константы; экспорт
   базового списка остаётся. `App`: вычислять видимые вкладки — «Связи» включается после
   «Таблицы и поля» только при `selectedTables.length > 1`; при скрытии активной вкладки
   «Связи» переключать `activeTab` на «Таблицы и поля» (через `useEffect`).
3. `App`: рендер `ConnectionsTab` при `activeTab === 'Связи'`; прокинуть экшены связей и
   `ExpressionBuilder` (поля всех таблиц — `qualifiedFieldsAllTables`).
4. `ConnectionsTab`: таблица связей с колонками `№`, `Таблица 1`, `Все`, `Таблица 2`,
   `Все`, `П.`, `Условие связи` (см. спек). Стиль — как `ConditionsTab` (inline-стили,
   vscode-переменные). Выпадающие списки полей — из метаданных выбранной таблицы (учесть
   виртуальные поля периода, как в `ConditionsTab.tableFields`).
