## Шаги

### 6.13.1 — core: классификация ПО + per-conjunct custom + рендер скобок ✅
- `queryModel.ts`: `JoinCondition { custom; leftTableId?; leftPath?; operator?; rightTableId?;
  rightPath?; expression? }`, `Join.conditions?: JoinCondition[]`; верхние поля `Join` —
  зеркало `conditions[0]` (back-compat UI).
- `sdblParser.ts`: `splitJoinConjuncts` (по верхнеуровневому `И`, с учётом скобок/`ВЫБОР`/
  `МЕЖДУ`) + `classifyJoinConjunct`. STANDARD iff `<chainRoot>.<путь> cmp <joined>.<путь>`
  (левый — поле КОРНЯ цепочки, правый — присоединяемой; оп сравнения; чистые поля). Иначе
  ARBITRARY. **Ключевое уточнение:** корень цепочки (`chainSeedAlias`), а не `seedTableId`
  (который у левоассоциативной цепочки = предыдущая присоединённая таблица).
- `sdblGenerator.ts`: `renderJoinConjuncts` — поконъюнктно, `(expr)` при custom иначе `expr`;
  откат к форматеру для сложных конъюнктов (`ИЛИ`/`ВЫБОР`/подзапрос).
- Фикстуры `0087`–`0090` (стандарт/параметр/перестановка/составное).
- **Итог: принято 1717 → 1758 (+41), mismatch 259 → 218, 0 регрессий.** Коммит `1590c3b`.

### 6.13.2 — webview: строка на конъюнкт, галочка «Произвольное» ✅
- `ConnectionsTab.tsx`: одна строка на (соединение, конъюнкт); галочка «Произвольное» из
  `conditions[i].custom`; редакторы поле/оператор/поле (custom=false) или текст+«…»
  (custom=true); per-row «+»/«✕».
- `queryStore.ts`: сеттеры с `condIndex`; `ADD_JOIN_CONDITION`/`REMOVE_JOIN_CONDITION`;
  синхронизация зеркала `conditions[0]`. `App.tsx` — проводка.
- Контракт `loadModel`→`parseBatch`→`LOAD_BATCH` несёт `conditions[]` без изменений.
- +4 unit-теста (per-conjunct + round-trip). **accept:oracle без изменений (1758/0).**
  Коммит `2770e8e`.
