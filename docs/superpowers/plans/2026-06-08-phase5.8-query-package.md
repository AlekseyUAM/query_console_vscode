# План — Фаза 5.8 «Пакет запросов»

Спек: `docs/superpowers/specs/2026-06-08-phase5.8-query-package-design.md`. TDD обязателен.
База — зелёная после 5.7. Каждая задача завершается зелёными `npm run test:unit` и
`npm run build`.

## Задача 1 — Ядро: документ пакета + `generateBatch` (pure-TS, TDD)

**Файлы:** `src/core/query/batchModel.ts` (новый), `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. `batchModel.ts`: тип `BatchDocument { members: QueryDocument[] }`.
2. `sdblGenerator.ts`: `generateBatch(batch): string`.
   - `SEP = '\n;\n\n' + '/'.repeat(80) + '\n'`.
   - Сгенерировать `members.map(generateDocument)`, отфильтровать `''`, склеить `SEP`.
   - 0 → `''`; 1 → ровно `generateDocument(members[0])` (без `;`/разделителя).
3. Тесты (TDD), эталоны ТЗ посимвольно: 1 член (== generateDocument); 2 члена с
   разделителем (80 `/`); член `УНИЧТОЖИТЬ`; пустые члены отбрасываются; `assertValidSdbl`
   на каждом непустом члене.

## Задача 2 — Webview: batch-слой стора (TDD)

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`.

1. Типы/состояние: `BatchSnapshot`, поля `activeBatch`, `batchSaved`; `initialState`
   (`activeBatch: 0`, `batchSaved: [null]`).
2. Хелперы: `snapshotActiveBatch`, `restoreBatch`, `batchMemberName(state, i)`,
   `assembleBatch(state)` (см. спек).
3. Экшены `ADD_BATCH_QUERY`, `SET_ACTIVE_BATCH`, `REMOVE_BATCH_QUERY`, `MOVE_BATCH_QUERY`
   (зеркало слоя объединения на `batchSaved`/`activeBatch`).
4. Тесты: изоляция working set между запросами пакета; имя для createTemp/dropTemp/
   обычного; `assembleBatch` из снимков; запрет удаления последнего; перемещение
   сохраняет активный.

## Задача 3 — Webview: BatchTab + боковая полоса + вставка

**Файлы:** `src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/BatchTab.tsx` (новый), `src/webview/components/FieldsPanel.tsx`.

1. `TabsBar`: «Пакет запросов» — последняя вкладка.
2. `BatchTab`: тулбар (⊕/✕/↑/↓), колонка `Запрос` (`batchMemberName`), двойной клик →
   `SET_ACTIVE_BATCH`, выделение активной. Стиль — как `UnionsTab`.
3. `App`:
   - рендер `BatchTab` при `activeTab === 'Пакет запросов'`;
   - боковая полоса привязана к пакету: `batchSaved.length > 1 && activeTab !== 'Пакет
     запросов'`, клик → `SET_ACTIVE_BATCH`, подписи `batchMemberName`;
   - `visibleTabs`: при `state.queryType === 'dropTemp'` → `['Дополнительно', 'Пакет
     запросов']`;
   - `handleShowQuery` и текст для `FieldsPanel` — через `generateBatch(assembleBatch(state))`.
4. `FieldsPanel`: принимать готовый `queryText` пропом; «ОК» → `formatAsBslString` +
   `onInsert`.
