# План — Фаза 5.2 «Условия»

Спек: `docs/superpowers/specs/2026-06-07-phase5.2-conditions-design.md`. TDD обязателен.

## Задача 1 — Ядро: модель + генератор (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. Добавить типы `ConditionOperator`, `Condition` и `conditions?: Condition[]` в
   `QueryModel`.
2. В `generate(...)` добавить рендер секции `ГДЕ` **после источников `ИЗ`, до
   `СГРУППИРОВАТЬ ПО`** (см. спек, формат и эталон). Хелпер `renderConditions`.
   Текст простого условия и произвольного — по спеку; пустые произвольные
   пропускаются; первое условие без `И`, последующие с `И`.
3. Тесты (сначала падающие): одно простое условие; два простых (`И`); произвольное;
   совместно с группировкой (порядок ГДЕ→СГРУППИРОВАТЬ ПО); отсутствие/пустые условия
   не меняют вывод; `assertValidSdbl` на тексте с ГДЕ.

## Задача 2 — Webview: store + ConditionsTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/App.tsx`, `src/webview/components/ConditionsTab.tsx` (новый).

1. `queryStore`: `conditions: Condition[]` в state (инициализация `[]`), экшены
   `ADD_CONDITION`, `REMOVE_CONDITION`, `SET_CONDITION_CUSTOM`,
   `SET_CONDITION_OPERATOR`, `SET_CONDITION_PARAM`, `SET_CONDITION_EXPRESSION`
   (иммутабельно, по индексу). Тесты на ключевые экшены.
2. `App`: рендер `ConditionsTab` на вкладке «Условия» (вместо placeholder);
   прокинуть `conditions` в `generate(...)` в `handleShowQuery` и в `FieldsPanel`
   (через проп, как `grouping`). Для произвольного условия — переиспользовать
   существующий `exprBuilder`-механизм App (как для полей): открыть ExpressionBuilder
   с доступными полями выбранных таблиц (qualified) и применить результат в
   `SET_CONDITION_EXPRESSION`.
3. `ConditionsTab`: левая панель «Поля» (drag-источник, `Псевдоним.Поле` выбранных
   таблиц), правая таблица условий (Номер/П./Условие) с оператором-select и
   param-input для простых, «…» для произвольных. Drop поля → `ADD_CONDITION`. Стиль —
   как другие панели.
