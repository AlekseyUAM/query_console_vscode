## Шаг 1 — Синонимы источников (7.8.11/12/13/16)  [TDD]

Файлы: `state/queryStore.ts`, `components/TablesPanel.tsx`, `App.tsx`,
`test/unit/queryStore.phase79.test.ts`, `test/e2e/webview.spec.ts`.

1. `ADD_TABLE`: убрать ранний возврат на дубль `fullName`; назначать `alias =
   base+k` при занятом базовом псевдониме (`base = defaultTableAlias({fullName})`).
2. `ADD_FIELD_WITH_TABLE`: убрать ранний возврат на дубль `(tableId, base)`;
   при наличии ≥1 такого поля — `alias = base+count` (`base` = последний сегмент).
3. Новое действие `ADD_ALL_FIELDS_DUP { tableId }` — добавляет все поля таблицы
   как новые колонки с синонимами (7.8.16), не пропуская существующие.
4. `TablesPanel`: строка показывает `defaultTableAlias(sel)` (title=fullName);
   `onDoubleClick` строки → `onAddAllFields(id)`.
5. Тесты unit (синонимы таблиц/полей, ADD_ALL_FIELDS_DUP) + e2e (двойной клик).
