# План — Фаза 5.4 «Объединения/Псевдонимы»

Спек: `docs/superpowers/specs/2026-06-07-phase5.4-unions-design.md`. TDD обязателен.
Самая крупная фича фазы 5; делится на 3 задачи, строго последовательно.

## Задача 1 — Ядро: unionModel + generateDocument + рефактор блока (pure-TS, TDD)

**Файлы:** `src/core/query/unionModel.ts` (новый), `src/core/query/sdblGenerator.ts`,
`test/unit/unionModel.test.ts` (новый), `test/unit/sdblGenerator.test.ts`.

1. `unionModel.ts`: типы `UnionMember`, `UnionColumn`, `QueryDocument`; чистая функция
   `deriveUnionColumns(members)` (см. спек: порядок по первому появлению псевдонима,
   `cells[i]` = выражение поля или null). Хелперы псевдонима/выражения поля.
2. Рефактор `sdblGenerator.ts`: выделить построитель блока запроса, принимающий готовые
   строки полей (массив строк ВЫБРАТЬ без запятых), чтобы `generate` и `generateDocument`
   его переиспользовали. **`generate(model)` обязан остаться байт-в-байт** (все
   существующие тесты зелёные).
3. `generateDocument(doc)` по спеку: 0/1/≥2 членов; `КАК` только у первого; NULL для
   отсутствующих; разделитель `ОБЪЕДИНИТЬ [ВСЕ]` по `member.distinct`.
4. Тесты: `deriveUnionColumns`; `generateDocument` 1 член = `generate`; 2 члена —
   все четыре эталона из `tmp/объединения.md`; distinct → `ОБЪЕДИНИТЬ`; `assertValidSdbl`.

## Задача 2 — Store: многозапросность + союзные экшены (TDD)

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`.

1. Добавить `queryList`, `activeQuery`, `savedQueries` в `QueryState` (init: один
   «Запрос 1»). `SavedQuery` + сериализация плоского состояния ↔ снимок.
2. Хелпер `assembleMembers(state)` (экспортировать для App/тестов).
3. Экшены: `ADD_QUERY`, `REMOVE_QUERY`, `SET_ACTIVE_QUERY`, `RENAME_QUERY`,
   `SET_QUERY_DISTINCT`, `SET_COLUMN_ALIAS` (обновляет `field.alias` во всех членах с
   колонкой). По возможности `MOVE_COLUMN`, `SET_COLUMN_CELL` (иначе — ограничение в
   отчёте). Существующие экшены не ломать (они работают с активным плоским состоянием).
4. Тесты: переключение запросов сохраняет/восстанавливает состояние; add/remove;
   rename alias меняет псевдонимы во всех членах; distinct.

## Задача 3 — UI: UnionsTab + боковые вкладки запросов + генерация документа

**Файлы:** `src/webview/App.tsx`, `src/webview/components/UnionsTab.tsx` (новый),
`src/webview/components/FieldsPanel.tsx`.

1. Боковые вертикальные вкладки запросов (показывать при >1 запросе) на всех вкладках;
   клик → `SET_ACTIVE_QUERY`.
2. `UnionsTab`: список запросов (Имя редактир. → RENAME_QUERY, Без дупликатов →
   SET_QUERY_DISTINCT, добавить/удалить) + таблица «Список полей» из
   `deriveUnionColumns(assembleMembers(state))` (редактирование псевдонима с валидацией
   и сообщением). Стрелки/remap — по возможности.
3. Генерация: заменить `generate(model)` на `generateDocument(assembleMembers(state))`
   в `handleShowQuery` и в `FieldsPanel` (через проп — массив членов или готовый текст).
   При одном запросе вывод идентичен прежнему.
