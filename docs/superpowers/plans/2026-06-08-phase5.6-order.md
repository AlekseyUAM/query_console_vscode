# План — Фаза 5.6 «Порядок»

Спек: `docs/superpowers/specs/2026-06-08-phase5.6-order-design.md`. TDD обязателен.
База — зелёная после 5.5. Каждая задача завершается зелёными `npm run test:unit` и
`npm run build`.

## Задача 1 — Ядро: модель + генератор `renderOrder` (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. В `queryModel.ts`: типы `SortDirection`, `OrderField`, `Order` и поле `order?: Order`.
2. В `sdblGenerator.ts`:
   - Хелпер `selectAliasFor(model, tableId, path)`: `alias` поля из `model.fields`,
     иначе последний сегмент `path` (переиспользуется и в 5.7).
   - Хелпер `renderOrder(order, model): string[]`: секция `УПОРЯДОЧИТЬ ПО` с полями
     (`<псевдоним>` + ` УБЫВ` при desc, запятые), и/или строка `АВТОУПОРЯДОЧИВАНИЕ`
     (см. спек).
   - В `generate()`: после `buildQueryBlock` — если `renderOrder` непуст,
     `out += '\n\n' + orderLines.join('\n')` (пустая строка-разделитель).
3. Тесты (TDD): возрастание; убывание; авто+поле; только авто; неактивный order не
   меняет вывод; `assertValidSdbl` на каждом. Эталоны ТЗ посимвольно.

## Задача 2 — Webview: store + TabsBar + OrderTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/OrderTab.tsx` (новый).

1. `queryStore`: поле `order: Order` в `QueryState`/`SavedQuery` (инициализация
   `{ fields: [], auto: false }`); протянуть через snapshot/restore/buildModelFromFlat/
   initialState. Экшены `ADD_ORDER_FIELD`, `REMOVE_ORDER_FIELD`, `SET_ORDER_DIRECTION`,
   `SET_ORDER_AUTO`. Каскад: `REMOVE_TABLE`/`REMOVE_FIELD` чистят `order.fields`. Тесты.
2. `TabsBar`: добавить «Порядок» в конец списка (после «Объединения/Псевдонимы»).
3. `App`: рендер `OrderTab` при `activeTab === 'Порядок'`; прокинуть `order` в генерацию
   (уже идёт через `assembleMembers`/`buildModelFromFlat`).
4. `OrderTab`: два списка — «Поля» (draggable, выбранные поля выборки) и «Сортировка»
   (колонки `Поле`, `Сортировка`-выпадающий список, кнопка удаления) + галочка
   «Автоупорядочивание». Стиль — как `GroupingTab`.
