# План — Фаза 5.3 «Дополнительно»

Спек: `docs/superpowers/specs/2026-06-07-phase5.3-additional-design.md`. TDD обязателен.

## Задача 1 — Ядро: модель + генератор (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. Типы `Selection`, `QueryType`; поля `selection?`, `queryType?`, `tempTableName?`,
   `lockForUpdate?` в `QueryModel`.
2. Генератор:
   - В начале `generate`: при `queryType==='dropTemp'` вернуть `УНИЧТОЖИТЬ <имя>` (или
     `''` без имени), до прочих проверок.
   - Первая строка `ВЫБРАТЬ` + модификаторы (`РАЗРЕШЕННЫЕ`, `РАЗЛИЧНЫЕ`, `ПЕРВЫЕ n`) в
     заданном порядке.
   - Строка `ПОМЕСТИТЬ <имя>` / `ДОБАВИТЬ <имя>` между полями и `ИЗ` (если имя задано).
   - Секция `ДЛЯ ИЗМЕНЕНИЯ` в самом конце с пустой строкой-разделителем и полными
     именами таблиц.
   - Все секции опциональны; при отсутствии — вывод как раньше.
3. Тесты (сначала падающие) по эталонам ТЗ + комбинации с ГДЕ/группировкой;
   `assertValidSdbl`.

## Задача 2 — Webview: store + AdditionalTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/App.tsx`, `src/webview/components/FieldsPanel.tsx`,
`src/webview/components/AdditionalTab.tsx` (новый).

1. `queryStore`: поля `selection` (init `{}`), `queryType` (init `'select'`),
   `tempTableName` (init `''`), `lockForUpdate` (init `[]`), `lockEnabled` (init
   `false`); экшены из спека (иммутабельно). `SET_LOCK_ENABLED(false)` очищает
   `lockForUpdate`. Тесты.
2. `App`: вкладка «Дополнительно» → `AdditionalTab`; прокинуть `selection/queryType/
   tempTableName/lockForUpdate` в `generate(...)` (handleShowQuery) и в `FieldsPanel`
   (новые пропсы, как `grouping`/`conditions`).
3. `AdditionalTab`: группы «Выборка записей» и «Тип запроса», поле имени ВТ, чекбокс
   блокировки + два списка (Таблицы / Таблицы для изменения) с переносом. Стиль — как
   другие вкладки. Список «Таблицы» = `selectedTables`; перенос добавляет полное имя в
   `lockForUpdate`.
