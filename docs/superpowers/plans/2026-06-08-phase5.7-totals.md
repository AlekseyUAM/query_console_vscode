## Задача 1 — Ядро: модель + генератор `renderTotals` (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. В `queryModel.ts`: типы `TotalKind`, `TotalGroupField`, `TotalField`, `Totals` и поле
   `totals?: Totals`.
2. В `sdblGenerator.ts`:
   - Хелпер `renderTotals(totals, model): string[]` с использованием
     `selectAliasFor` (из 5.6): список агрегатов (`expression ?? СУММА(<псевдоним>)`),
     список ПО (с `ОБЩИЕ` при `grand`, суффиксы типа итогов, `КАК <alias>`), два формата
     (`ИТОГИ … ПО …` / `ИТОГИ ПО …`) — см. спек.
   - В `generate()`: после секции `УПОРЯДОЧИТЬ ПО` — если `renderTotals` непуст,
     `out += '\n' + totalsLines.join('\n')` (без пустой строки-разделителя).
3. Тесты (TDD): Элементы; Элементы и иерархия; Только иерархия; псевдоним группировки;
   итоговое поле `СУММА(...)`; «Общие итоги»; неактивные итоги не меняют вывод;
   `assertValidSdbl` на каждом. Эталоны ТЗ посимвольно.

## Задача 2 — Webview: store + TabsBar + TotalsTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/TotalsTab.tsx` (новый).

1. `queryStore`: поле `totals: Totals` в `QueryState`/`SavedQuery` (инициализация
   `{ groupFields: [], totalFields: [], grand: false }`); протянуть через
   snapshot/restore/buildModelFromFlat/initialState. Экшены `ADD_TOTAL_GROUP_FIELD`,
   `REMOVE_TOTAL_GROUP_FIELD`, `SET_TOTAL_GROUP_KIND`, `SET_TOTAL_GROUP_ALIAS`,
   `ADD_TOTAL_FIELD`, `REMOVE_TOTAL_FIELD`, `SET_TOTAL_FIELD_EXPRESSION`,
   `SET_TOTAL_GRAND`. Каскад: `REMOVE_TABLE`/`REMOVE_FIELD` чистят итоги. Тесты.
2. `TabsBar`: добавить «Итоги» в конец (после «Порядок»).
3. `App`: рендер `TotalsTab` при `activeTab === 'Итоги'`.
4. `TotalsTab`: слева «Поля» (draggable); справа — «Группировочное поле» (поле, тип
   итогов-выпадающий список по ссылочности, псевдоним-текст), галочка «Общие итоги»,
   «Итоговое поле» (поле, выражение-текст; дроп только числовых — переиспользовать
   `isNumericField`/`findMetaField` из `GroupingTab`, вынести в общий модуль или
   продублировать). Стиль — как `GroupingTab`.
