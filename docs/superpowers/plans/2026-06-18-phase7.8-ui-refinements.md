# Подфаза 7.8 — план реализации

← [спек](../specs/2026-06-18-phase7.8-ui-refinements-design.md) · [PHASE_7.md](../../PHASE_7.md)

Девять независимых пунктов. Изолированные части (ядро кэша, стиль вкладок) —
параллельными субагентами; связанное ядро webview (App/store/панели/окна) — единым
проходом во избежание конфликтов по `App.tsx`/`queryStore.ts`.

## Шаги

1. **7.8.1 (ядро+хост).** `modelCache.ts`: вынести `writeModelCache`, добавить
   `rebuildModelCache`. `panel.ts`: вызвать его в `refreshCache`. Тест
   `modelCache.test.ts`.
2. **7.8.2 (хост+webview).** `messages.ts`: `init { hasInitialQuery }`. `panel.ts`:
   слать `init` перед `metadataTree`. `App.tsx`: оверлей загрузки + флаги.
3. **7.8.3 (хост).** `package.json`: `queryConsole.openInNewWindow`. `panel.ts`:
   `moveEditorToNewWindow` под настройкой, ошибки гасить.
4. **7.8.4/7.8.5 (webview).** `FieldsPanel`: проп `onEditField` (двойной клик) +
   включение «+». `App`: «+» → ExpressionBuilder со всеми полями; двойной клик →
   ExpressionBuilder + `SET_FIELD_EXPRESSION`. Редьюсер `SET_FIELD_EXPRESSION`. e2e.
5. **7.8.6 (webview).** `FieldsPanel.handleDrop` ← `kind:'table'`; строки `TablesPanel`
   делаем draggable. Редьюсер `ADD_ALL_FIELDS_WITH_TABLE`. e2e.
6. **7.8.7 (webview).** `TabsBar` — сегментный стиль. Юнит `tabsBar.test.ts` зелёный.
7. **7.8.8 (webview).** `SubqueryDialog`; кнопка `⊂З` в `TablesPanel`; `App` парсит и
   шлёт `ADD_SUBQUERY_TABLE`. Редьюсер + синтетическая метатаблица.
8. **7.8.9 (webview).** `TempTableDialog`; кнопка `ВТ`; редьюсер `ADD_TEMP_TABLE`.
9. **Проверка.** `test:unit` (vitest) + `test:e2e` (Playwright) зелёные; визуальная
   сверка бандла; код-ревью; коммит в master.
