# Фаза 8.1. Сохранение комментариев — план реализации

← [спек](../specs/2026-06-19-phase8.1-comments-design.md)

Подход: TDD, слой за слоем. Жёсткий инвариант на каждом шаге — `npm run test:unit`
зелёный, в т.ч. `oracleGolden`/`corpusRegression` без изменений.

Канонический приёмочный пример (текст запроса, без BSL-обёртки `|`):

```
ВЫБРАТЬ
	Валюты.Ссылка КАК Ссылка, // комментарий 1-го вида
// комментарий 2-го вида
	Валюты.Наименование КАК Наименование
ПОМЕСТИТЬ Вал
ИЗ
	Справочник.Валюты КАК Валюты
;

////////////////////////////////////////////////////////////////////////////////
// комментарий 3-го вида
ВЫБРАТЬ
	Бригады.Ссылка КАК Ссылка
ИЗ
// комментарий 4-го вида
	Справочник.Бригады КАК Бригады
```

## Шаг 1 — Модель (`queryModel.ts`)
- Добавить `QueryComments`, `QueryModel.comments?`, `SelectedField.commentLeading?`,
  `SelectedField.commentTrailing?`. Чисто типы — тестов нет. `tsc` чист.

## Шаг 2 — Лексер (`sdblLexer.ts`) [тест: `sdblLexer.comments.test.ts`]
- `TokenType` += `'comment'`. `tokenize(text, opts?)`. При `comments:true` эмит токена.
- Тест: дефолт не эмитит; с опцией — эмитит с верными `line`/`text`.

## Шаг 3 — Связыватель (`commentBinder.ts`) [тест: `commentBinder.test.ts`]
- `extractComments(memberText, model)`. Покрыть 4 вида, отбрасывание прочих, игнор `////…`.
- Вход моделей в тестах строить через `parseQuery`/`parseBatch` (single-member).

## Шаг 4 — Парсер (`sdblParser.ts`)
- 3-й арг `opts` у `parseBatch`/`parseDocument`; при `preserveComments` — `extractComments`
  на чанках с одним участником, в try/catch. Существующие вызовы не трогаем.

## Шаг 5 — Генератор (`sdblGenerator.ts`) [тест: `commentsGenerate.test.ts`]
- `buildQueryBlock`: beforeSelect/afterFrom/leading/trailing. Без комментариев — прежний вывод.

## Шаг 6 — Приёмка round-trip [тест: `commentsRoundTrip.test.ts`]
- `generateBatch(parseBatch(SPEC, undefined, {preserveComments:true}))` === SPEC.
- Также: `parseBatch(SPEC)` (без опции) → `generateBatch` === SPEC без комментариев.

## Шаг 7 — Состояние (`queryStore.ts`) [тест: `queryStore.comments.test.ts`]
- Протяжка `comments` через snapshot/restore/model-конвертеры/assembleBatch.
- Сброс: SET_TEMP_TABLE_NAME, SET_QUERY_TYPE, SET_COLUMN_ALIAS, SET_FIELD_EXPRESSION.
- `stripComments(batch)` хелпер. Тесты на правила сброса + сквозную загрузку→сборку.

## Шаг 8 — UI/поток (`App.tsx`, `validateBatch.ts`)
- `tryParseBatch(text, opts?)`. Чекбокс «Сохранять комментарии» (default on) в `cacheToolbar`.
- Загрузка с `{preserveComments:true}`; вставка с учётом галочки (`stripComments`).
- Сборка webview (`npm run build:webview`) чистая.
