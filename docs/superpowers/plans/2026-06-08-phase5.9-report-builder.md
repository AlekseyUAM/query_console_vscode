# План — Фаза 5.9 «Построитель»

Спек: `docs/superpowers/specs/2026-06-08-phase5.9-report-builder-design.md`. TDD обязателен.
База — зелёная после 5.8. Каждая задача завершается зелёными `npm run test:unit` и
`npm run build`.

## Задача 1 — Ядро: модель + блоки `{…}` (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. `queryModel.ts`: типы `BuilderField`, `ReportBuilder`; поле `builder?: ReportBuilder`.
2. `sdblGenerator.ts`:
   - `builderBlock(keyword, fields): string[]` — `[]` при пустом списке; иначе
     `{<keyword>` + строки `\t<ref>[.*][ КАК alias]` (запятые, `}` приклеен к последней).
   - Встроить в `buildQueryBlock`: `{ВЫБРАТЬ}` после `...lines`; `{ГДЕ}` после
     `conditionLines`; `{УПОРЯДОЧИТЬ ПО}` после `groupingLines`; `{ИТОГИ ПО}` следом —
     всё до `lockLines`. Одиночный перенос (см. спек).
3. Тесты (TDD), эталоны ТЗ посимвольно: четыре блока; `.*`; `КАК`; `child`+`alias`
   вместе; пустой `builder` не меняет вывод. (Без `assertValidSdbl` для `{…}`-секций.)

## Задача 2 — Webview: builder в сторе (TDD)

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`.

1. `builder: ReportBuilder` в `QueryState`/`SavedQuery`; инициализация
   `{ fields: [], conditions: [], order: [], totals: [] }`; протянуть через
   `snapshotActive`/`restoreSaved`/`buildModelFromFlat`/`initialState`.
2. Экшены `ADD_BUILDER_FIELD`/`REMOVE_BUILDER_FIELD`/`SET_BUILDER_FIELD_CHILD`/
   `SET_BUILDER_FIELD_ALIAS` с `section` и индексом.
3. Тесты: add/remove/child/alias по каждой секции; `builder` переживает snapshot/restore
   запроса пакета (5.8) и участника объединения (5.4).

## Задача 3 — Webview: BuilderTab + под-вкладки

**Файлы:** `src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/BuilderTab.tsx` (новый).

1. `TabsBar`: «Построитель» перед «Пакет запросов».
2. `BuilderTab`: вторичная полоса под-вкладок `Поля`/`Условия`/`Порядок`/`Итоги`; общий
   двухпанельный экран (дерево «Поля» + список с колонками `Поле`/`И.`/`Псевдоним`,
   кнопки `>`/`>>`/`<`/`<<`, ↑/↓). Вычисление `ref` по правилу под-вкладки (псевдоним
   выборки или `Алиас.Поле`; «Все поля» → `Алиас.Поле`). Источник полей и раскрытие
   ссылок — как в `OrderTab`/`TotalsTab`/`DbTreePanel`.
3. `App`: рендер `BuilderTab` при `activeTab === 'Построитель'`; прокинуть экшены
   построителя. (Генерация уже идёт через `builder` в модели.)
