# План — Фаза 5.1 «Группировка»

Спек: `docs/superpowers/specs/2026-06-07-phase5.1-grouping-design.md`. TDD обязателен.
Базовый коммит — зелёный (320 unit-тестов). Каждая задача завершается зелёными
`npm run test:unit` и `npm run build`.

## Задача 1 — Ядро: модель + генератор SDBL (pure-TS, TDD)

**Файлы:** `src/core/query/queryModel.ts`, `src/core/query/sdblGenerator.ts`,
`test/unit/sdblGenerator.test.ts`.

1. В `queryModel.ts` добавить типы `AggregateFunction`, `FieldRef`, `SummableField`,
   `Grouping` и опциональное поле `grouping?: Grouping` в `QueryModel` (см. спек).
2. В `sdblGenerator.ts`:
   - Хелпер `wrapAggregate(func, expr)` → строка по таблице маппинга из спека.
   - В цикле по `model.fields`: если поле (по `tableId+path`) есть в
     `grouping.aggregates`, обернуть `Псевдоним.Поле` функцией; alias-правила как
     сейчас. Произвольные поля (`expression`) и поля ТЧ не группируются.
   - После блока `ИЗ` добавить секцию `СГРУППИРОВАТЬ ПО` / `…ГРУППИРУЮЩИМ НАБОРАМ`
     по формату из спека. Рендерить только если группировка активна и есть поля
     группировки/наборы.
3. Тесты (TDD — сначала тест): обёртки всех 6 функций; одна группировка; несколько
   наборов; пустой `grouping` не меняет вывод; `await assertValidSdbl(text)` на
   результатах с группировкой (helper `test/helpers/assertValidSdbl.ts`).

## Задача 2 — Webview: store + вкладки + GroupingTab

**Файлы:** `src/webview/state/queryStore.ts`, `test/unit/queryStore.test.ts`,
`src/webview/components/TabsBar.tsx`, `src/webview/App.tsx`,
`src/webview/components/GroupingTab.tsx` (новый).

1. `queryStore`: добавить в `QueryState` поле `grouping: Grouping` (инициализация —
   `{ multiple:false, groupFields:[], groupSets:[], aggregates:[] }`), экшены из спека.
   Тесты на ключевые экшены (add/remove group field, add summable + set func,
   toggle multiple, операции с наборами).
2. `TabsBar`: принять `active`, `onSelect`, список вкладок (Таблицы и поля,
   Группировка, Условия, Дополнительно, Объединения/Псевдонимы) — переключаемые;
   неготовые вкладки могут быть видимы, но 5.1 наполняет только Группировку.
3. `App`: состояние `activeTab`; рендер контента по вкладке (существующие 3 панели —
   на «Таблицы и поля»; `GroupingTab` — на «Группировка»). Прокинуть `grouping` в
   `generate(...)` в `handleShowQuery`; так же при вставке (`FieldsPanel.handleOk` —
   прокинуть grouping через проп или поднять генерацию в App).
4. `GroupingTab`: три списка (Поля / Поле группировки / Суммируемое поле+Функция),
   drag&drop из «Поля», выбор функции (числовой/нечисловой набор по типу поля),
   галочка «несколько группировок» с деревом наборов. Стиль — как существующие панели
   (inline-стили, vscode-переменные).
