Опись собрана по скриншотам, снятым драйвером `tooling/real-constructor/` с **живого**
веб-клиента 1С (УНФ 3.0, публикация `smallb`) на 10 сложных запросах из корпуса. По

(`00-constructor-opened.png`) и по скриншоту на каждую вкладку (`NN-<вкладка>.png`).

Назначение — визуальный референс настоящего конструктора как вход для доработки нашего
webview и как основа оракула Подфазы 7.4 (сверка «наш конструктор vs реальный»).

## Общий каркас окна

- Заголовок формы: **«Конструктор запроса»**, стрелки «назад/вперёд», «✕» (закрыть).
- Строка вкладок: `Таблицы и поля · [Связи] · Группировка · Условия · Дополнительно ·
  Объединения/Псевдонимы · [Индексы] · Итоги · [Пакет запросов]`.
- Нижняя панель (на всех вкладках): **«Редактируемый запрос:»** (выпадающий список
  запросов пакета), **«Редактируемый оператор:»** (Запрос 1, …), кнопки **«Запрос»**,
  **«ОК»**, **«Отмена»**, **«?»** (справка). Кнопки — `span.pressBox`.
- Колонки-списки оснащены кнопками переноса **`>`/`>>`/`<`/`<<`** и меню **«Еще ▾»**.

## Вкладки

### Таблицы и поля
Три панели: **«База данных»** (дерево метаданных: Критерии отбора, Планы обмена,
Константы, Справочники, Документы, Журналы документов, Перечисления, Планы видов
характеристик, Планы счетов, Планы видов расчёта, Регистры сведений/накопления/
бухгалтерии, Бизнес-процессы, Задачи) → **«Таблицы»** (выбранные таблицы) → **«Поля»**
(выбранные поля; псевдо-узлы `ВЫБОР…` для выражений, «Все поля»). У каждой панели своя
командная панель и «Еще ▾».

### Связи
Одна панель **«Таблица»** — дерево соединений: ведущая таблица → присоединённая, столбец
**типа связи** (Левое/…), под ними — текст условия связи. Командная панель: добавить/
удалить связь.

### Группировка
Слева список **«Поля»** (поля доступных таблиц, `ВЫБОР…`, «Все поля»). Справа сверху —
**«Поле группировки»** с флажком **«Использовать несколько группировок»**; справа снизу —
**«Суммируемое поле»**. Перенос — `>`/`>>`/`<`/`<<` отдельными группами.

### Условия
Слева дерево **«Поля»**, справа список **«Условие»** (тексты условий, например
`ЗаказПокупателя.Ссылка = &Ссылка`). Командная панель условий: добавить, удалить,
сгруппировать (И/ИЛИ), произвольное условие.

### Дополнительно
- **«Выборка записей»**: флажки «Первые [N]», «Без повторяющихся», «Разрешенные».
- **«Тип запроса»** (радио): «Выборка данных» / «Создание временной таблицы» /
  «Добавление во временную таблицу»; поле **«Имя временной таблицы»**.
- Флажок «Блокировать получаемые данные для последующего изменения».
- Внизу: список **«Таблицы»** ↔ **«Таблицы для изменения»** с переносом.

### Объединения/Псевдонимы
Слева список **«Запросы»** (объединяемые запросы), в центре **«Имя поля»**, справа —
колонка псевдонимов на каждый запрос («Запрос 1», …): задание псевдонимов полей и
сопоставление полей объединения.

### Индексы
Слева список индексов — колонки **«Имя»** и **«Уникальный»** (флажок); командная панель
add/копировать/del/вверх/вниз. В центре дерево **«Поля»**, справа **«Поле»** (поля
индекса) с переносом и кнопками порядка ↑/↓.

### Итоги
Поля для итогов (выбор полей группировки и суммируемых для конструкции ИТОГИ … ПО …),
структура аналогична «Группировке» (вкладка появляется не на всех запросах корпуса —
зависит от наличия итогов/применимости).

### Пакет запросов
Список **«Запросы»** пакета (ВременнаяТаблицаШапка, …, «Запрос пакета N»). Командная
панель: **«Добавить ▾»**, удалить, вверх/вниз. Выбор строки переключает «Редактируемый
запрос» нижней панели — все остальные вкладки начинают относиться к выбранному запросу
пакета.

## Кандидаты в доработку нашего webview

Сопоставление с нашими вкладками (Фаза 5) — вход в задачи:

- **Динамический набор вкладок.** Реальный конструктор показывает «Связи» только при
  >1 таблице, а «Пакет запросов»/«Объединения» — по составу запроса. Стоит свериться,
  что наш UI так же управляет видимостью.
- **«Дополнительно».** Тип запроса (выборка / создание / добавление во временную
  таблицу) + блок «Таблицы для изменения» — проверить покрытие.
- **«Индексы».** Колонка «Уникальный», порядок полей индекса (↑/↓) — детали для сверки.
- **Нижняя панель «Редактируемый запрос / Редактируемый оператор».** Контекст пакета и
  оператора объединения общий для всех вкладок — ключевой для UX пакета/объединений.

Точный пиксель-/поведенческий дифф — задача Подфазы 7.4 (оракул = реальный конструктор).
