# Внешняя обработка: выгрузка эталонных запросов к метаданным

Внешняя обработка 1С, которая формирует «эталонный» корпус запросов ко всем
объектам метаданных конфигурации и сохраняет их нормализованные тексты в файлы.
Полученные файлы — вход для корпусного тестирования конструктора запросов
(см. [`docs/corpus-testing.md`](../../docs/corpus-testing.md)).

## Что делает

При выполнении команды «Выгрузить» обработка на сервере обходит все коллекции
метаданных и для каждого объекта формирует запрос:

- объекты с одной основной таблицей (Справочники, Документы, Перечисления,
  Планы видов характеристик, Планы счетов, Планы видов расчёта, Планы обмена,
  Бизнес-процессы, Задачи) — `ВЫБРАТЬ * ИЗ <Тип>.<Объект>`;
- регистры сведений — основная таблица + виртуальные таблицы `СрезПервых`,
  `СрезПоследних`;
- регистры накопления — основная таблица + `Остатки`, `Обороты`,
  `ОстаткиИОбороты`;
- регистры бухгалтерии — основная таблица + `Остатки`, `Обороты`,
  `ОстаткиИОбороты`, `ДвиженияССубконто`, `ОборотыДтКт`.

Для виртуальных таблиц оборотов (`Обороты`, `ОстаткиИОбороты`, `ОборотыДтКт`)
запрос формируется отдельно на каждую периодичность, подставляемую третьим
параметром виртуальной таблицы: `Запись`, `Период`, `Регистратор`,
`НомерСтроки`, `Секунда`, `Минута`, `Час`, `День`, `Неделя`, `Месяц`,
`Квартал`, `Год`, `Декада`, `Полугодие`, `Авто`.

Каждый сформированный текст валидируется через `СхемаЗапроса`:

```bsl
Схема = Новый СхемаЗапроса;
Схема.УстановитьТекстЗапроса(ТекстЗапроса);  // в попытке — невалидные отбрасываются
ТекстЗапроса = Схема.ПолучитьТекстЗапроса(); // нормализованный текст оракула
```

В файл сохраняется именно текст, полученный через `ПолучитьТекстЗапроса()`
(нормализованный платформой), а не исходная строка. Запросы, на которых
`СхемаЗапроса` бросает исключение (например, к несуществующей виртуальной
таблице), молча пропускаются. Валидация выполняется на сервере (`СхемаЗапроса`
недоступна на тонком клиенте); на клиент возвращается соответствие
«имя файла → текст запроса», и запись файлов идёт уже на клиенте.

## Как запустить

1. Открыть `ВыгрузкаЗапросовКМетаданным.epf` в 1С (Файл → Открыть) на базе с
   нужной конфигурацией.
2. Указать каталог выгрузки в реквизите формы `КаталогВыгрузки` (путь
   относительно текущего каталога клиента 1С) — он должен совпадать со значением
   `META_QUERIES_DIR` из `.env` корпусного теста (по умолчанию `tmp/meta1c`).
3. Выполнить команду «Выгрузить». Тексты запросов будут записаны в указанный каталог.

По завершении обработка показывает количество сохранённых файлов.

## Формат имени файла

```
[ТипМетаданных]_[Объект][_ВиртуальнаяТаблица][_Периодичность].txt
```

Сегменты `_ВиртуальнаяТаблица` и `_Периодичность` присутствуют только когда они
заданы. Примеры:

```
Справочник_Валюты.txt
РегистрСведений_КурсыВалют_СрезПоследних.txt
РегистрНакопления_Продажи_Обороты_Месяц.txt
```

## Состав каталога

- `ВыгрузкаЗапросовКМетаданным.epf` — скомпилированная внешняя обработка
  (бинарь для открытия в 1С).
- `ВыгрузкаЗапросовКМетаданным.bsl` — исходник модуля формы обработки
  (для просмотра/правок логики выгрузки).
